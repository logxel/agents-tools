# Verification Matrix

| Area | Evidence required |
| --- | --- |
| Discovery | The skill, agents, and commands appear under their expected V2 IDs. |
| Scope | Changed files stay within the plan and ownership boundaries. |
| Behavior | Focused tests or a reproducible manual check pass. |
| Regression | Relevant broader checks pass or an existing failure is recorded. |
| Permissions | Read-only roles cannot edit or run shell commands. |
| Resume | An interrupted task can continue from the dated plan and evidence. |
| Tooling | MCP or CLI tools are available only when explicitly configured and needed. |
| Handoff | The final report includes commands, results, residual risk, and next action. |

Missing evidence is an unresolved risk, not a pass.
