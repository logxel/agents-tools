# OpenCode Documentation

This directory records the OpenCode V1 to V2 migration baseline and the
final native OpenCode V2 addon.

- [Migrate from OpenCode V1 to V2](opencode-v1-to-v2.md)
- [OpenCode V2 addon baseline](opencode-v2-addon.md)

The guidance is based on the [OpenCode V2 migration guide](https://opencode.ai/v2/docs/migrate-v1),
[V2 skills reference](https://opencode.ai/v2/docs/skills),
[V2 agents reference](https://opencode.ai/v2/docs/agents). Re-check upstream
behavior when upgrading OpenCode because V2 APIs and plugin compatibility are
still moving.
